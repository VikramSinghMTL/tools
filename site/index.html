Tools

Small browser-based tools for teaching. Everything runs locally in your browser.

  • ✂️ Gradescope PDF Trimmer Trim a Gradescope export's PDFs to the first N pages and rename them by student ID.
  • 💯 Moodle → Lea Grade Export Bookmarklet that copies grades from Moodle's gradebook for Lea's import page.
  • 📅 Course Calendar Builder Edit a course calendar as JSON and preview it live.
